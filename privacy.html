Privacy Policy

LevelPlot Uploader · last updated 18 September 2026

1. Who we are

LevelPlot Uploader ("the tool") is an internal publishing tool of the LevelPlot video channel. It is operated by the channel owner for the channel owner's own YouTube channel only. Contact: CONTACT_EMAIL.

2. Use of YouTube API Services

The tool uses the YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data the tool accesses

After the channel owner signs in with Google (OAuth 2.0), the tool receives an access token with the youtube.upload permission for the owner's channel. With it the tool only:

  • uploads videos created by LevelPlot to the owner's channel;
  • writes the video metadata (title, description, tags, category, language, publishing time);
  • sets the video thumbnail.

The tool does not read or collect data about YouTube viewers, subscribers, comments, other channels or any other users.

4. How data is stored

The OAuth access and refresh tokens are stored only on the channel owner's computer and are used only to make the uploads described above. The response of the API (the ID of the uploaded video) is kept in local logs of the owner. No data is stored on third-party servers, sold, shared or used for advertising.

5. Sharing

The tool does not share any data obtained through the YouTube API Services with anyone. Uploaded videos become public on YouTube only when the owner publishes them.

6. Cookies

The tool is a command-line program: it does not use cookies or similar technologies and does not place any on your device. This website does not use cookies or trackers.

7. Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. After access is revoked the stored tokens stop working and are deleted from the owner's computer; nothing else is retained. To request deletion of any data, write to CONTACT_EMAIL — requests are handled within 7 days.

8. Changes

If this policy changes, the updated version will be published on this page with a new date.
